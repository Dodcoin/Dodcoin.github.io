Projects

WHEELY FM — generative radio engine

A browser-based generative music application written in vanilla JavaScript. A WebAudio composition engine polls a public telemetry API every 15 seconds and composes music in real time — tempo, note density and filter brightness are functions of the live data stream. No recordings, no playlists, no backend: one static HTML file containing the full synthesis engine, a canvas visualisation and a session-statistics module.

Stack: JavaScript, WebAudio API, Canvas, REST polling · Source: github.com/Dodcoin/wheely-fm

On-chain automation tooling

Node.js and Python automation I develop for BNB Smart Chain: contract-call builders, eligibility checkers and monitoring scripts that read chain state over JSON-RPC and construct transaction calldata programmatically, with simulation checks before anything is signed.

Stack: Node.js, Python, web3, JSON-RPC, EVM calldata
